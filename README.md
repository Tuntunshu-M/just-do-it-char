# 导演时间

“导演时间”是 SillyTavern 1.18 前端扩展。它使用结构化导演请求规划事件、伏笔和人物行动，再把本轮导演指令临时交给 SillyTavern 生成正文。扩展不会改写角色卡，也不会把完整剧本永久塞进聊天上下文。

## 快速开始

1. 在 SillyTavern 扩展管理器中选择“从 URL 安装”。
2. 输入 `https://github.com/Tuntunshu-M/just-do-it-char.git`，安装后刷新页面。
3. 打开单角色聊天，在输入框旁的魔杠菜单中点击“导演时间”。
4. 点击标题旁的齿轮，在“连接”中选择“当前主连接”或配置独立 API。
5. 回到“人物”和“世界书”核对上下文，在“偏好”中设置事件类型与触发规则。
6. 在“事件”中输入想法并手动创建；也可以把事件想法留空，让导演根据当前聊天、人物和所选世界书随机创建事件。

面板始终居中显示。点击遮罩不会关闭面板；使用右上角关闭按钮或 `Esc` 关闭。

## 页面索引

| 页面 | 用途 |
| --- | --- |
| 事件 | 查看当前事件、填写导演指令、手动创建、暂停、恢复、重抽和改变方向 |
| 伏笔 | 查看当前聊天中保留的伏笔 |
| 人物 | 查看人物识别结果、证据和侧写，进行锁定、校正、合并或拆分 |
| 世界书 | 读取已安装的全部世界书，由用户逐本、逐条决定是否参考 |
| 偏好 | 设置事件权重、题材、触发方式、时段、安全词和重大后果权限 |
| 副本 | 选择迁移内容，导出、预览导入和撤销导入 |
| 设置 → 连接 | 选择主 API 或独立兼容 API，测试连接能力 |
| 设置 → 检查 | 只读检查环境，查看最近 20 条事件生成诊断记录 |
| 标题栏太阳/月亮 | 显示当前白天/夜晚模式，点击即可切换界面颜色 |
| 设置 → 外观 | 预览、保存、停用、导入或导出主题，并下载 CSS 美化模板 |

## 事件生成流程

导演流程依次采集聊天、人物和所选世界书条目，生成结构化事件，校验人物依据与安全规则，临时注入导演提示，再调用 SillyTavern 正文生成。成功后事件与伏笔写入当前聊天状态；手动请求若判断为“本次不生成事件”，不会继续注入或生成正文。

可用触发方式包括智能混合、固定回合、每回合和空闲触发。冷却、每日上限与允许时段会共同限制自动触发。原生群聊当前会暂停导演生成。

手动创建时，“事件想法”可以留空。确认框会显示“随机事件”，导演会结合当前聊天、人物资料、导演指令和用户勾选的世界书条目自行构思；填写想法时则继续按该想法创建或扩展。

## 世界书选择

“世界书”页读取 SillyTavern 中安装的全部世界书，包括全局世界书，而不只读取当前角色绑定的世界书。首次展开一本世界书时加载其条目；可以整本全选、全不选，也可以只勾选需要参考的条目。只有用户选中的内容会进入导演上下文。

## 设置与检查

齿轮设置分为“连接”“检查”“外观”三页。

“运行检查”只读取当前聊天、扩展开关、连接模式、SillyTavern 生成能力、保存能力和世界书列表，不请求模型，也不创建事件。它与连接页的“测试连接”不同：测试连接会验证所选连接能否执行生成能力，而运行检查只做本地只读巡检。

事件失败或未生成时，酒馆会立即显示简要提示，并指向“设置 → 检查”。检查页为每个聊天保留最近 20 条记录，包括触发方式、结果、阶段、时间、耗时和错误摘要。可复制诊断报告或清空当前聊天的记录。

诊断记录和报告不会保存 API Key、Authorization、完整提示词、聊天正文或模型原始响应。常见 Bearer Token、`sk-...` 密钥、API 地址和 URL 查询参数在记录前会统一脱敏；错误摘要最长保留 500 个字符。

## 外观与 CSS 美化

“导演时间”标题旁的图标显示当前界面模式：夜晚模式显示月亮，白天模式显示太阳；点击图标可在两种模式间切换。白天模式使用白色底、黑色字、黑色按钮和白色按钮文字；夜晚模式使用黑色底、白色字、白色按钮和黑色按钮文字。选择会保存在全局扩展设置中，刷新后继续生效。次要说明文字在两种模式下都使用较高对比度颜色。

- “导出主题”下载当前主题配置的 JSON，可在另一套酒馆中通过“导入主题”恢复。
- “导出 CSS 模板”下载 `proactive-director-template.css`，包含全部公开颜色变量、面板、标签、按钮、输入控件、世界书和诊断记录的常用选择器。
- 默认情况下，自定义 CSS 只作用于导演时间插件。只有明确启用“允许全局 CSS”后才会影响酒馆其他界面。
- CSS 模板和主题文件都不包含 API Key、聊天记录、人物卡或世界书内容。

## 连接与隐私

选择“当前主连接”时，导演结构化生成和正文生成使用 SillyTavern 当前配置的主 API。用户无需在扩展中重复填写密钥，适合日常使用。选择独立 API 时，需要填写 OpenAI Chat Completions 兼容地址、API Key 和模型；可以拉取模型并设置温度、最大输出与流式生成。

独立 API 失败不会自动回退到主连接。API Key 仅保存在 SillyTavern 全局扩展设置中，不进入聊天状态、副本、主题或诊断报告。

## 安全与偏好

高风险模式默认关闭，启用前必须填写至少一个安全词并再次确认。安全词和硬禁区支持中文逗号 `，`、英文逗号 `,` 或换行分隔；清空安全词会自动关闭高风险模式。安全词、场外停止、硬禁区和立即停止始终拥有最高优先级。

重大后果可分别设置为禁止、先询问或允许。副本导入安全数据后，高风险开关仍会恢复为关闭状态。

## 副本迁移

迁移模式会同步勾选对应内容：自定义模式由用户逐项选择；保守模式只迁移低风险事件框架；克隆模式迁移事件框架、历史、人物推断、规则账本和安全设置。导入前会显示摘要与警告，应用后可撤销最近一次导入。

## 故障排查

- 魔杠菜单没有入口：确认扩展已启用并刷新 SillyTavern。
- 入口能看到但不能点击：更新到最新版本并确认没有旧版扩展文件残留。
- 面板关闭按钮不可见：刷新页面以加载最新 CSS；面板应限制在当前视口中央。
- 自动事件没有触发：检查类别开关、触发模式、冷却、每日上限和允许时段。
- 世界书没有内容：在“世界书”页确认已启用读取，展开世界书并勾选需要的条目。
- 事件失败或没有生成：先看酒馆即时提示，再到“设置 → 检查”运行巡检并复制诊断报告。
- 独立 API 失败：检查接口地址、API Key、模型以及 `/models`、`/chat/completions` 兼容性。
