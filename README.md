# 主动导演

主动导演是一个 SillyTavern 前端扩展。它根据当前角色卡、聊天上下文和用户偏好规划事件、伏笔与下一步行动，让角色以符合自身人格的方式主动推进剧情。角色正文仍由 SillyTavern 当前连接生成，扩展只负责导演状态、策略判断和临时行动提示。

## 主要功能

- 生活日常、突发危机、色情向三类事件独立开关和权重。
- 现实、奇幻、科幻、无限流、鬼怪灵异、末日、自定义等题材模式。
- 混合智能、固定回合、每回合三种触发方式。
- 当前事件、伏笔、人物、偏好、连接、外观、副本七个控制台页面。
- 单角色卡和一张卡内多人物识别；原生 SillyTavern 群聊会暂停导演推进。
- 使用当前主连接，或配置独立的 OpenAI Chat Completions 兼容 API。
- 事件事务、停止、暂停、重抽、方向调整、状态保存和选择性副本迁移。
- 仅作用于插件根节点的 CSS 主题变量和自定义 CSS。

## 安装

在 SillyTavern 的扩展管理器中选择从 URL 安装，输入：

```text
https://github.com/Tuntunshu-M/just-do-it-char.git
```

安装后刷新或重启 SillyTavern。

## 快速操作

1. 打开任意单角色聊天。
2. 点击输入框旁的原生魔棒按钮。
3. 在魔棒菜单中点击“主动导演”。
4. 居中控制台会打开。使用顶部标签切换事件、伏笔、人物、偏好、连接、外观和副本。
5. 点击右上角 `×` 或按 `Esc` 关闭面板。点击遮罩空白处不会关闭面板。
6. 在“事件”页面可以输入事件想法，例如“让 char 策划旅行”，然后选择是否让 AI 扩展。

扩展设置页不会再直接显示整块控制台；入口只保留在输入框旁的原生魔棒菜单中。若菜单被其他扩展重建，主动导演会自动重新挂载菜单项。

## API 配置

“连接”页面提供两种模式：

- **当前主连接**：复用 SillyTavern 当前连接，不需要额外 API Key。
- **独立兼容 API**：填写接口地址、API Key 和模型名称，扩展请求 `/chat/completions`。

独立 API 失败时不会自动切换主连接。API Key 只保存在全局扩展设置中，不进入聊天状态、聊天副本或主题文件。

## 事件与边界

“偏好”页面可以调整三类事件的开关、权重、题材、触发方式、用户意愿优先级和重大后果权限。禁止项由本地策略在模型调用前后再次拦截，模型无法绕过本地禁止规则。

### 高风险模式（色情向）

该模式默认关闭，并且必须先填写安全词才能启用。

- 安全词为空时点击开关，会提示：`请先填写安全词。`
- 没有安全词时不会显示确认提示，也不会勾选开关。
- 填写至少一个安全词后点击开关，仍会先显示确认提示。
- 清空安全词会自动关闭高风险模式。
- 安全词、硬禁区、场外停止和立即停止始终拥有最高优先级。

## 主题与 CSS

根节点为 `#st-proactive-director`，公开类名使用 `stpd-` 前缀。默认 CSS 只作用于插件面板；主题变量和导入导出格式见 [CSS 主题文档](./docs/css-theming.md)。

自定义 CSS 默认限制在插件根节点内。全局 CSS 只有在设置中明确开启后才会生效，可能影响 SillyTavern 主界面和其他扩展。

## 故障排查

- 魔棒菜单没有入口：刷新页面，确认扩展已启用，并检查是否有其他菜单精简扩展覆盖了 `#extensionsMenu`。
- 面板没有打开：查看浏览器控制台中的第一条扩展错误，确认 `index.js`、`style.css` 和 `src/` 文件加载成功。
- 没有自动事件：确认当前不是群聊，事件分类已开启，触发条件、冷却和每日上限允许运行。
- 独立 API 失败：检查接口地址是否包含正确的服务前缀、API Key 和模型名称。
