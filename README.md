# 导演时间

“导演时间”是 SillyTavern 1.18 的前端扩展，用来帮助角色在聊天中准备事件、伏笔和阶段性剧情。

## 安装

1. 在 SillyTavern 的扩展管理器中选择“从 URL 安装”。
2. 输入本项目 GitHub 地址并安装。
3. 刷新页面，在输入框旁的魔杖菜单中打开“导演时间”。

## 第一次使用

1. 打开“设置 → 连接”。选择“当前主连接”，或填写独立 API 的地址、API Key 和模型。
2. 打开“世界书”，展开需要使用的书，勾选整本书或指定条目。全局世界书也会列在这里。
3. 打开“人物”，检查角色卡资料和人物侧写。侧写由模型压缩生成，引用资料默认折叠在“引用资料”中。
4. 在“偏好”中设置事件类别、触发方式、用户主导程度、安全词和硬禁区。

## 创建事件

在“事件”页填写想法后点击“创建事件”。想要随机事件时可以留空，确认后扩展会准备一份剧情大纲、拆分步骤和伏笔，并显示简短通知：

> TA 似乎悄悄准备了什么

事件大纲不会替用户发送消息，也不会直接生成角色正文。你继续正常输入 RP 后，SillyTavern 的主 API 会按照当前步骤生成角色回复。下一次用户输入会被用于判断继续推进、修改后续步骤、保持当前方向或停止事件。

事件页可以查看当前大纲、每一步的状态、伏笔和历史版本。修改大纲后，已经发生的事实会保留；历史大纲可在“历史大纲”中恢复，保存数量可在设置中限制为 1 到 3 个。

## 世界书

“世界书”页会读取酒馆中已安装的全部世界书，包括全局世界书。展开书名后可以：

- 勾选整本书；
- 只勾选需要参考的条目；
- 使用搜索框查找书名或条目；
- 使用“全选”或“全不选”。

选择条目后页面会保留当前位置，方便连续选择。只有勾选的内容会用于导演和人物侧写。

## 人物侧写

人物侧写会参考角色卡的描述、性格、场景、示例对话，以及用户选中的世界书条目，生成一份更短的角色资料。世界书原文不会直接摊在侧写正文中。

当角色卡或世界书选择发生变化时，已有侧写会标记为“资料已变化”。点击“刷新人物侧写”后才会再次调用模型。

## 设置

- **连接**：配置主连接或独立 API，并测试连接。
- **检查**：运行本地诊断，查看当前状态、检查结果和最近的事件生成记录。
- **外观**：编辑主题 CSS、预览、保存、导入/导出主题，或导出 CSS 美化模板。

标题栏旁的图标用于切换昼夜主题：夜间显示月亮，点击后切换到白天；白天显示太阳，点击后切换到夜间。

## 生成失败时

失败会立即显示简短中文原因，例如“模型返回空内容”“模型输出被截断”“模型返回格式错误”或“模型连接失败”。进入“设置 → 检查”可以查看详细诊断，并复制脱敏后的报告。

## 迁移副本

在“副本”页选择要迁移的内容，再导出或导入副本。自定义、保守和克隆模式会同步勾选对应内容；导入前会显示预览和警告，导入后可以撤销最近一次导入。

## 故障排查

- 菜单没有入口：确认扩展已启用并刷新酒馆。
- 入口能看到但打不开：更新扩展后再次刷新，确认没有旧版本文件残留。
- 世界书为空：确认“世界书”开关已打开，并展开书名加载条目。
- 没有生成事件：先查看酒馆提示，再到“设置 → 检查”运行诊断。
- 独立 API 失败：检查兼容 OpenAI Chat Completions 的地址、模型和 API Key。
