# 导演时间

导演时间是 SillyTavern 1.18 前端扩展。它使用结构化副 API 规划事件、伏笔和角色行动，再把本轮紧凑导演指令临时交给 SillyTavern 当前主连接生成正文。扩展不会改写角色卡，也不会把完整剧本永久塞进正文上下文。

## 主要功能

- 日常、危机、色情向事件可独立开关并设置权重。
- 支持智能混合、固定回合、每回合和空闲触发，以及冷却、每日上限和允许时段。
- 支持现实、奇幻、科幻、无限流、鬼怪灵异、末日和自定义题材。
- 单角色模式会根据角色卡、示例对白和所选世界书条目生成人物侧写。
- 多人卡支持人物识别、别名、证据隔离、人物锁定和主导人物切换校验；原生群聊暂停导演生成。
- 事件支持预览确认、暂停、恢复、停止、重新抽取和改变方向；已发生事实不会被改线重写。
- 无限流和灵异题材持续维护公开规则、假说、禁忌、目标、物品、人物知情状态、异常和隐藏真相。
- 可使用当前主连接或独立 OpenAI Chat Completions 兼容 API。独立 API 支持拉取模型、温度、最大输出、超时和流式/非流式生成。
- 顶栏状态会显示采集中、生成中、流式生成中、注入中、完成或失败。
- 可选择迁移事件、历史、人物推断、规则账本、安全词和硬禁区，并支持撤销导入。
- 自定义 CSS 默认只作用于插件，可预览、保存、停用、恢复、重置、导入和导出。

## 安装与入口

在 SillyTavern 扩展管理器中选择“从 URL 安装”，输入：

```text
https://github.com/Tuntunshu-M/just-do-it-char.git
```

安装后刷新或重启 SillyTavern。扩展设置页不会直接显示大型面板；请点击聊天输入框旁的原生魔棒按钮，再选择“导演时间”。面板居中显示，点击空白遮罩不会关闭，只能按 `Esc` 或右上角 `×` 关闭。

## 操作指引

1. 打开单角色聊天，在魔棒菜单中进入“导演时间”。
2. 在“人物”页核对角色卡与世界书形成的人物侧写；多人卡可锁定识别结果。
3. 在“世界书”页选择是否读取世界书，并选择全部条目或指定条目。
4. 在“事件”页填写导演指令。手动事件想法可写“让 char 策划旅行”，确认预览后才会生成。
5. 在“偏好”页设置事件权重、题材、触发模式、允许时段、用户意愿优先级和重大后果权限。
6. 在“连接”页选择主连接或独立 API。独立 API 可拉取模型并测试连接。
7. 生成期间查看面板顶栏状态；停止按钮会清除活动事件和待注入内容。
8. 在“外观”和“副本”页管理主题与选择性迁移。

## 高风险模式（色情向）

“高风险模式（色情向）”默认关闭，必须先填写至少一个安全词。

- 安全词为空时点击开关，提示 `请先填写安全词。`，不显示确认框，开关保持关闭。
- 已填写安全词时，启用前仍显示确认提示。
- 清空安全词会自动关闭高风险模式。
- 安全词、场外停止、硬禁区和立即停止始终拥有最高优先级。
- 死亡、永久伤残、怀孕、生育、重大疾病、长期失踪、永久关系破裂和巨额财产变化分别支持禁止、先询问或允许。

## 连接与隐私

当前主连接首次使用会提示 `正在在用主api哦！`，确认后 24 小时内不重复提示。独立 API 失败不会自动回退主连接。

API Key 仅存于 SillyTavern 全局扩展设置，不进入聊天状态、副本或主题文件。副本也不会包含高风险开关状态和重大后果授权。导入安全数据时，高风险开关始终恢复为关闭。

## 故障排查

- 魔棒菜单没有入口：刷新页面并确认扩展已启用。
- 固定回合没有触发：检查类别开关、冷却、每日上限和允许时段。
- 世界书没有条目：确认当前角色或聊天已绑定世界书，并在“世界书”页启用读取。
- 独立 API 失败：检查接口地址、API Key、模型和 `/models`、`/chat/completions` 兼容性。
- 原生群聊不生成：这是首版的预期行为，面板会显示暂停提示。
