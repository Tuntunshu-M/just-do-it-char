# 剧本删除与空闲触发禁用设计

## 目标

在当前聊天的剧本记录页增加单选/多选删除与清空操作，同时保护运行中和暂停中的剧本；将尚未实现的空闲触发控件明确标注并禁用。

## 行为

- 剧本列表每条记录显示复选框，`running` 和 `paused` 记录不可选中。
- “删除所选”删除已选中的可删除记录；没有可删除选择时禁用。
- “清空本聊天”删除当前聊天内所有可删除记录，保留 `running` 和 `paused`。
- 删除前通过现有确认对话框确认；确认文案包含将删除数量，若有运行中/暂停中记录则说明这些记录会保留。
- 删除完成后保持 selectedScriptId 指向剩余有效记录，否则置空；activeScriptId/activeEvent 始终不被删除操作清除。
- 空闲触发标签显示“启用空闲触发（还没做）”；启用开关、空闲分钟、允许时段三个控件全部禁用，不改变存储值。

## 技术方案

- `script-repository.js` 提供按 ID 删除与清空当前聊天可删除剧本的事务接口，删除保护在仓库层执行，避免 UI 绕过。
- `script-list.js` 维护本次渲染的选中 ID 集合，通过复选框回调传给 `scripts.js`；列表按钮仍负责选择详情，复选框阻止冒泡避免误选详情。
- `scripts.js` 渲染批量工具条并调用 services；`index.js` 将 repository 操作接入控制台并刷新状态。
- 删除测试覆盖仓库保护、单选、多选、清空和空列表；偏好 UI 测试覆盖标签与 disabled 属性。

## 非目标

- 不删除运行中或暂停中的剧本，不提供强制删除入口。
- 不实现空闲触发逻辑，只禁用并标注现有设置。
