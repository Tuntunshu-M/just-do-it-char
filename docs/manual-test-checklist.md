# SillyTavern 手动验收清单

- [ ] 通过 GitHub URL 安装并重启 SillyTavern。
- [ ] 单角色卡：用户发言后导演生成计划，正文由当前主连接生成。
- [ ] 多人卡：人物拆分、别名、证据归属和主导人物切换正确。
- [ ] 原生群聊：面板显示暂停且不调用导演 API。
- [ ] 主连接：出现“正在在用主api哦！”，确认后 24 小时不再提醒。
- [ ] 独立兼容 API：请求成功；连接失败时不回退主连接。
- [ ] 独立 API 可拉取模型，温度、最大输出和流式开关实际进入请求。
- [ ] 顶栏依次显示采集中、生成中、注入中和完成；失败时显示错误状态。
- [ ] 日常、危机、色情向开关和占比分别生效。
- [ ] 无限流/灵异：公开规则、假说、禁忌、物品和人物知情状态持续更新。
- [ ] 安全词、场外停止和停止按钮立即清除事件与待注入提示。
- [ ] 副本选择性导入、人物映射、安全词迁移与撤销正常。
- [ ] 自定义 CSS 预览、保存、停用、回滚和窄屏布局正常。
- [ ] 桌面和手机视口均无横向滚动；点击遮罩不关闭，`Esc` 和 `×` 可以关闭。

本仓库的自动化测试使用宿主桩。发布前仍需在真实 SillyTavern 中完成以上两种 API 连接的烟雾测试。
